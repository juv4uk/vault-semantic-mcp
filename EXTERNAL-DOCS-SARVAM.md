# Офіційна документація Sarvam AI (MCP Server)

Цей документ описує офіційні можливості інтегрованого MCP-сервера `sarvam-ai`, його ліміти та специфіку роботи з локальними пайплайнами (зокрема для задач NLP в рамках WSM).

## 1. Загальна інформація про Sarvam AI
Sarvam AI — це спеціалізована екосистема ШІ для мов Індійського субконтиненту. Вона створена для роботи з Indic Languages.
**Мови, які підтримує платформа (стандартний набір):**
- Хінді (`hi-IN`), Бенгальська (`bn-IN`), Гуджараті (`gu-IN`), Каннада (`kn-IN`), Малаялам (`ml-IN`), Маратхі (`mr-IN`), Одія (`od-IN`), Пенджабі (`pa-IN`), Тамільська (`ta-IN`), Телугу (`te-IN`), Санскрит (`sa-IN`), Англійська (`en-IN`).
- **Увага:** Платформа **не підтримує** українську (`uk-UA`). Для інтеграції потрібен IR (Intermediate Representation) міст, як-от гінді або англійська.

## 2. Ключові API інструменти (Tools)

Сервер `sarvam-ai` експонує такі інструменти (доступні через MCP):

### 1. `translate_text`
- **Опис:** Переклад тексту між підтримуваними індійськими мовами та англійською.
- **Параметри:** `source_language_code`, `target_language_code`, `text`, `model`.
- **Рекомендована модель:** `sarvam-translate:v1`.
- **Особливість для Санскриту:** Це єдиний надійний інструмент для семантичної роботи з `sa-IN`, який розрізняє тонкощі термінології.

### 2. `analyze_text` (Наразі статус: 404 / Недоступно)
- **Опис:** Раніше використовувався для аналізу тексту, але станом на сьогодні цей ендпоінт відключений розробниками Sarvam API або вимагає іншого формату підписки. Для генерації абстракцій замість нього слід використовувати `translate_text`.

### 3. `transliterate_text`
- **Опис:** Транслітерує текст з однієї писемності (наприклад, латинки/IAST) в іншу (наприклад, Devanagari).
- **Корисність:** Критично важливо для `my-lisp-panini` (для переведення IAST у Devanagari перед Phonetic Vector Compilation).

### 4. `identify_language`
- **Опис:** Автоматично визначає мову та писемність фрагменту тексту (з Indic-пулу).

### Аудіо-інструменти (Speech-to-Text / Text-to-Speech)
- `speech_to_text`: Транскрипція індійських мов.
- `text_to_speech`: Озвучка (наприклад, читання Шлок санскритом чи гінді).
- `speech_to_text_translate`: Прямий переклад голосу в текст іншою мовою.

## 3. Рекомендації для екосистеми WSM (My-Lisp)

1. **Моделі Sarvam:** Завжди явно вказуйте `model: "sarvam-translate:v1"`. Замовчувана `mayura:v1` може видавати помилки для певних мов (особливо `sa-IN`).
2. **Batching (Пакетна обробка):** API Sarvam має rate-ліміти. При написанні оркестратора на Ліспі (`orchestrator.wsm`) обов'язково розбивайте корпус на дрібні батчі (по 10-15 текстів). 
3. **Обмеження контексту:** Sarvam API має жорсткі ліміти на кількість символів в одному запиті на переклад. Великі тексти (наприклад, цілі розділи Аштядхьяї) треба різати (`chunking`).
