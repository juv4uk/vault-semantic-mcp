## Перевірено, але НЕ скопійовано — потребує окремого рішення власника

Ці ресурси реально існують і мають дані, але копіювання — значно
більша дія (git clone цілого репозиторію, потенційно великі обсяги),
не робив без явного підтвердження:

- **Cologne Digital Sanskrit Dictionaries** (43 словники) — кожен
  словник свій репозиторій в GitHub-організації
  `github.com/sanskrit-lexicon` (код репо — типу `MWS`, `AP90`, `PWG`,
  точний список не перевірено; спроба клонувати `sanskrit-lexicon/MW`
  напряму дала 404 — назва репо для Monier-Williams інша, не
  перевірено яка саме). Розмір кожного репо не перевірено.
- **Amarakośa** (`github.com/sanskrit-lexicon/AMAR`) — джерельні дані
  на GitHub, повний текст — на сайті Cologne
  (sanskrit-lexicon.uni-koeln.de), не на landing-сторінці.
- **Sanskrit Heritage Site** — PDF-словник (7 МБ), XML морфологічний
  словник у кількох транслітераційних схемах, Zen Library (LGPL,
  OCaml) — усе реально завантажуване, конкретні URL не витягнуто
  (сторінка описує наявність, не дає прямих лінків цією перевіркою).
- **Sanskrit WordNet API** — дві різні URL з'явились у дослідженні:
  `sanskritwordnet.unipv.it/api` (Pavia/Exeter, оригінальне джерело
  власника) і `sanskritwordnet.chs.harvard.edu/api` (згадано
  WebFetch-підсумком другого запиту) — **ці дві адреси НЕ звірені
  одна проти одної, можливо це два різні проєкти або WebFetch
  переплутав джерело**. Перед використанням API — перевірити, яка
  адреса справжня, вручну відкривши обидві.
- **IIT Bombay Sanskrit WordNet** — жодного публічного API/даних не
  знайдено на самій сторінці; треба звертатись напряму до IRCC IIT
  Bombay.
- **Burba (2018), Гнатовська та інші статті** oriental-world.org.ua —
  лише DOI/цитата, повний текст не безкоштовний на перевіреній
  сторінці (можливо доступний через інституційний доступ чи Sci-Hub,
  не перевірялось і не рекомендується цією сесією).

## Явно НЕ зроблено

Масове клонування 43 словникових репозиторіїв Cologne — не зроблено:
невідомий сумарний розмір, невідома реальна потреба прямо зараз (лише
270 концептів онтології, не вся санскритська лексика). Той самий
принцип "складність заробляється продемонстрованою потребою", що вже
застосований сьогодні до GC/managed-heap та data-parallelism оцінок у
my-lisp.
