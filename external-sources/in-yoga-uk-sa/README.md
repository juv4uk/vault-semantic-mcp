## Перевірено й ВИКЛЮЧЕНО — мовна невідповідність

**Amarakośa, "переклад Ольги Неліної"** (сторінка
`sites.google.com/view/uasanskrit/translations/Amarakosha`) —
спочатку здавалось релевантним (той самий текст, що в `../AMAR/`), але
пряма перевірка сирого HTML показала: **"Автор перевода на русский
Ольга Нелина"**, "Этапы перевода с санскрита" — це переклад на
**російську**, не українську. НЕ скопійовано.

**Татяна Приходько — обидві приписані їй роботи виявились російськими,
не українськими.** Сама передмова `goraksha-yoga-shastra.pdf`
пояснює: *"Переклад російською було виконано безпосередньо з
санскритського варіанту тексту Тетяною Приходько. ... Переклад
українською виконували... Андрій Грабовий та Марта Коник"* — тобто
українську версію ЦІЄЇ Ж роботи зробили ІНШІ люди, не Приходько.
"Стрігурустотра" (`sites.google.com/uasanskrit`, той самий сайт, теж
описана російською: "Татьяна Приходько", "текст, собранный из
отрывков") — окремої підтвердженої української версії не знайдено, НЕ
скопійовано.
